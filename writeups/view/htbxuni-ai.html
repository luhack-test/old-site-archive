HTBxUni AI

HTBxUni AI was a misc challenge where we are given the information that there's a discord bot on Hack The Box Discord called HTB X Uni AI and we need to shut it down

Firstly we retrieved the Discord ID of this bot so we could try to invite him to some server where we could interact with him

So we get the ID 764609448089092119 Then using this ID we can invite the bot to our server using a Bot invite link that Discord has:

https://discord.com/oauth2/authorize?client_id=764609448089092119&scope=bot

Then We tried to use the !shutdown command that was given as an intruction in the challenge and the bot responded "You are not an Administrator, you can't tell me what to do smh..."

So we created a Role in Discord called Administrator

Finally we used the !shutdown command again and we got the flag:
